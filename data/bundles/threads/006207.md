So, in case you guys are studying these threads, there's another dwarf, dark purple/possibly black-ish clone of cephalotus called Walpole which is different from this clone, here's a write up on it for clarification purposes: [sarracenia.proboards.com/thread/6098/cephalotus-follicularis-walpole-allen-lowrie](https://sarracenia.proboards.com/thread/6098/cephalotus-follicularis-walpole-allen-lowrie)  
  
In contrast, this is a very different clone, quite possibly from a different population....who knows, "Walpole" is a huge generalization and there are many different sites in that general area.   This clone originates from Kalvin....nope, nope, nope.......Christian Klein, and it is described as having "large, colorful, distinctive pitchers."  In my short experience of having it, it's also quite vigorous and more forgiving than many other clones, but cephalotus in general are only so forgiving, so process that info relative to other Cephalotus clones.  Compared to Corn, this clone is impossible to grow, LOL   
  
One key characteristic of this clone is that it produces red coloration deeper into the trap.  Now, I checked a bunch of other clones to see if that happens and most don't have it but a few others do, so this trait alone won't distinguish this clone from others, but it's one of many other traits that can be used to help ID this particular individual.  
  
From my experience, Cephalotus sometimes need to "size up" to show off their unique characteristics and shapes: this Walpole division didn't produce large traps last season, so we'll see what it looks like this year!

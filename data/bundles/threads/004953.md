Here's an old clone that's been in the collection forever, but I almost lost it many times.  This clone can get really tall:  up to 3' in height!  It doesn't color up easily, but in the fall, when we have sunny days and cool nights, it can turn dark red!  This clone is incredibly vigorous, but like S. leucophylla, it doesn't like to sit in water for long periods of time (at least outdoors here in Northern California).    
  
I think there was a thread on this clone years back, but I can't find it and the pictures got wiped out anyways, so here's a new thread!    
  
Some of these traps got a bit burnt from a heat wave we had a few weeks back, but there are still some new traps developing.  Hopefully, there will be some better looking ones that will color up in the next few weeks, but for now, here's what I got!  Pics taken 9/7/20:

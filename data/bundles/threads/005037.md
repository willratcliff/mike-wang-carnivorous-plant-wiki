Maybe the name of this clone is a bit aggressive and possibly bully-like, but fortunately, plants don't have feelings (well, the jury is still out there for venus fly traps, but you catch my drift) or emotions.  I didn't call it egghead because that sounds insensitive.   (MW starts sweating, nervous laugh)  Maybe I'll end this portion of the description while I'm still ahead, haha!  
  
What does really catch pique my interest with roseas these days is phenotypic variation: a single clone can have so many different colors and shapes from one year to the next, from one season to the next, or from one trap to the next!  "Eggmouth" is a great example of this variation: it can form these extreme eggy shaped traps/mouth, but not always?  It's really weird, guys!  
  
Anyways, this small division has better shaped traps than the mother plant, so it'll have to rep. this clone for now!  Pics taken 10/12/20.  Unfortunately, it looks better in person than in the pics, as I didn't quite capture the round, eggy shape of this clone, but this will have to do for now:

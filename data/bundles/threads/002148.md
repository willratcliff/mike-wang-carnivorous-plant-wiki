Technically speaking, this is S. flava var. ornata 'Red lips' ((Gulf Coast,FL x black veins) clone B) x (black veins SFL05A)).  Gosh, I might have messed up the parenthesis on that, but Math ain't my forte.  
  
This clone consistently produces red lips, so it's a keeper in my book!  There's even more amazing individuals from this seed batch that I'm keeping an eye on, so stay tuned!  Anyhow, this red lipped clone grows fast, and it seems to form medium height pitchers.  It still hasn't reached maturity, so we'll see over time how tall they get.  Personally, I think they'll look great whether medium height or tall.  This is a brand new creation!

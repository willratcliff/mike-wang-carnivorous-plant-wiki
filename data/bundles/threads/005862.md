Here's a genotype that's new to the collection that hails from Michigan!  Previously, I've only grown one other type from MI (Oakland Co), and those are still alive and strong!    
  
Purpureas in general have given me a very hard time long term: they'll grow strong for a good 5-6 years and then CRASH!  Maybe it has to do with the fact that some populations are much like darlingtonia: they need their roots to stay cool!  So far, that's not true for a lot of the Ontario populations but many others have had a lot of rot issues despite seemingly perfect growing conditions.  Many  experiments are currently being run to get to the root cause of this issue.  
  
So far, these Clinton Co, MI purpureas haven't been rot prone or given any trouble, fingers crossed it'll be one of those genotypes that doesn't need to be grown like a Darlingtonia!

Here's a one of a kind clone that you don't run into...almost ever!  out of thousands of plants, this is the only wildtype clone from Covington Co, AL that has a very bright white top with some dark purple coloration that contrasts very well with the white coloration, causing it to catch the eye in person!  
  
When the traps first open, the color below the white is actually reddish, but as it ages, that's when it gets dark purple!    
  
truth be told, I've had this clone for a very long time and almost lost it several times.  Maybe 3 years ago, a tiny side shoot was salvaged, and over time, it was propagated to the point that now there are a few divisions in the collection.    
  
When this clone gets bigger, so do the colors, so to speak!  What you're seeing are traps that are medium to small in size, which means the clone isn't yet at its fullest color potential. Nevertheless, it's still pretty evident that this is a stellar, standout invidual!

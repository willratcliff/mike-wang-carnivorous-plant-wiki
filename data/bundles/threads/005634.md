Here's an old clone that hasn't ever been photo documented, it came from the same site where the type specimen was collected and used to describe the variant.  Today, it's a slash pine plantation!    
  
This clone has some nice colors, decent vigor, and nice windows!  It hasn't ever turned red like this before, so I don't want to call it such unless this trait consistently shows up.  These were recently transplanted after being neglected for a good 10 years, so maybe they just weren't happy in the past.

Holy Effin S!  That's the thought process upon noticing the traps on this particular clone this season, they've NEVER been this dark red before!    
  
  
I call this thing S. flava var. "atropurpurea" dark clone Cook's Bayou, Bay Co, FL with the word atropurpurea in quotation marks because the flowers are orangey red, suggesting this is the result of introgression.  This clone originated from a site that was destroyed quite a long time ago: today, the habitat has mostly been converted to slash pine plantations. There are relic patches that still exist, but the once vast fields of Sarracenia are long gone.  
  
  
Anyways, I just unofficially named this clone dark clone to distinguish it from other all red genotypes from the same area.  Pics taken 5/25/23.  Note the flower in the first pic:

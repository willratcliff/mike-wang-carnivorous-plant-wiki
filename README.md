# Carnivorous Plant Clone Wiki

An archive and wiki of carnivorous plant clones described by Mike Wang
(`meizzwang`) on https://sarracenia.proboards.com.

Built at Mike's request to preserve the clone history, origin, traits, and
cultivation notes in case the source forum becomes unavailable.

## Status

- Forum archive complete: 925 Mike-authored threads, 9939 posts, 16,973 images mirrored locally.
- Per-thread Markdown bundles in `data/bundles/threads/`.
- Wiki synthesis in progress: 2 clusters / 4 entries written under `wiki/`. Resumable via `data/parsed/clones/synthesis_progress.json`.

## For Claude Code sessions continuing this project

**Read `docs/session-startup.md` first.** It walks through the project
state, where to find the next work, the synthesis recipe, the quality
bar, and the patterns to watch for. Skim time: ~3 minutes.

## Per-clone fields (per Mike)

- Full name of the clone
- Origin
- History (approx. date entered cultivation)
- Standout traits
- Location data (county and state of origin)
- Photographs
- Cultivation notes

## Editorial model

Mike is the authoritative reviewer. AI assists with extraction and
synthesis from forum threads; Mike reviews and corrects every entry
before it is considered finalized.

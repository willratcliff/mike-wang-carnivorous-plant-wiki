# Sarracenia oreophila var. ornata 'purple throat' (UCB × MK017) 'select clone'

Mike-bred F1 from UCB (vigorous + late-coloring) × MK017 (small +
early-purple-throat). Best-of-both-parents result: vigorous + shapely
+ early-summer solid red throats + heavily veined. Among the only
oreophilas in cultivation that produces intense outdoor color in
